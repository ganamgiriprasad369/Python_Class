what is a Token ?
Token is a Small Unit.
Each Unit consider 5 ways:
-Identifier
-Operator
-literal
-keyword
-Delimiters (punctuators)


for example:
n = 10;		//Statement1
if n%2== 0:     // statement2: Any line of code is a statement
print("even")   //Statement3
else:		//statement4
print("odd")	//Statement5


This program divided into small pieces, these small pieces are called Tokens.
n -identifier
= - operator
10 -literial 
if -Keyword
n - identifier
% -operator
2-literial 
==-operator
0-literial 
print()-identifier
"Even"-literial
