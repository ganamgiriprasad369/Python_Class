Formatting Method: Align Text to string Specific width



1)center():Center alignment
places a string  in the center, to specified width


Syntax: string.center(width, fillchar) --fillchar(optional)




2)ljust():Left alignment

Places the string on the left and fills the remaining space on the right.

Syntax: string.ljust(width, fillchar)




3)rjust():Right alignment

Places the string on the right and fills the remaining space on the left.

Syntax: string.rjust(width, fillchar)








4)zfill():Add zeros to the left

Adds zeros to the beginning of a string until it reaches the specified width.

Syntax: string.zfill(width)



f.ljust(10, "-")
'banana----'

f.rjust(10, "_")

b = '125'
b.zfill(5)

Replace Method:

1)Replace(): Replaces occurrences of one substring with another substring.


Syntax: string.replace(old, new, count)

old: text to find

new: replacement text

count: optional maximum number of replacements


ex: Updating product descriptions, replacing words in text, or changing formatting in data.


____________________________________________________________________________________________________________________________________
Note : we replace only one character or substring. this disadvantage replace that why new replace method use 'translate & maketrans'
-------------------------------------------------------------------------------------------------------------------------------------

2)maketrans(): Create a translation table


maketrans() creates a mapping that tells Python which characters to replace when translate() is called.


Syntax: str.maketrans(old_chars, new_chars)

text1.maketrans('aeiou','12345')
{97: 49, 101: 50, 105: 51, 111: 52, 117: 53}// ASCLI character(Unicode value).




3)translate(s.maketrans()): Apply a translation table


Uses a translation table created by maketrans() to replace or remove characters.

Syntax: string.translate(table)


text1.translate(text1.maketrans('aeiou','12345'))
'j1ckj4n2s'
